## 🚀 What I've Built

- **Fuel Sensor Classification (GCP):** End-to-end pipeline on BigQuery telematics data using breakpoint detection and rule-based confidence gating. It replaced 100% manual inspection and runs autonomously every month.
- **Trip Detection for Mining & Construction:** Core algorithm behind trip counts on the Control Tower platform, with 98–99% accuracy despite GPS noise and rugged terrain. Includes an efficacy-monitoring framework and earned an Appreciation Letter from the Executive Vice President.
- **Geospatial Hotspot Clustering:** BIRCH + Haversine hierarchical clustering with boundary-aware refinement. It scales across India without proportional infrastructure growth.
- **MLOps & CI/CD:** GitHub Actions + GCP pipeline with automated quality checks, unit tests, Gitleaks secret scanning, Secret Manager and IAP-based VM deployment. Zero committed credentials.
- **Earlier work:** E-commerce sell-out forecasting models and Power BI automation that cut reporting time by 30%.
